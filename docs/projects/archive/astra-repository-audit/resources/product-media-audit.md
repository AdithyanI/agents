# Product and media repository audit

Read-only sample completed 2026-09-17 against the seven repositories below. This applies the supplied OpenAI Astra article and `agent-native-repo-playbook`: preserve concrete ownership and failure boundaries, remove obsolete procedural demands, make discovery conditional, and define completion through appropriate proof. No audited repository was edited; no application suite, provider call, deployment, publishing action, or financial workflow was run.

## Main finding

The roots are mostly already small. The largest opportunities are **hidden instructions in references and skills**, stale routing, and inconsistent release commands. AIP contains an explicit stop after Phase 1; WIN has an old mandatory testing manual; Remotion imposes a fixed reading itinerary. Small repositories can have drift too: Future of Life's 26-line root contradicts its current design contract. Do not use file count as a deletion quota.
