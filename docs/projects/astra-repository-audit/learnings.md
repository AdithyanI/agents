# Audit Learnings

## Observations

- Inventory must distinguish primary repos from worktrees, generated deployment copies, and dependency clones before recommending cleanup.
- Project evidence explains much of the apparent documentation volume; file count alone cannot identify instruction overhead.
- This audit should improve existing guidance and routing without creating a new standing policy layer.
