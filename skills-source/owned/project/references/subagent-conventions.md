# Parallel Project Work

Delegate when independent work can proceed alongside useful parent work. Keep coupled edits and moving shared contracts with one owner until the boundary is clear. Read-only investigation and isolated implementation are both valid; neither needs a mandatory preliminary stage.

Give each worker a bounded outcome, source/file ownership, relevant constraints, and a verification expectation. Use the roles actually available in the session rather than assuming a fixed role catalog.

Keep the tracker single-writer. Record delegated ownership there when it helps continuity, and integrate each result against current source and shared contracts. Workers can return concise findings without creating a permanent report file.

Bring work back to the parent when integration dominates or the split causes repeated conflict. A retrospective is useful only if it changes how future work should be done; routine delegation does not require another document.
